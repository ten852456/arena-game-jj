# 8 สาย + Ultimate ประจำฮีโร่ (ร่างออกแบบ ให้คุยกับ JJ)

สถานะ: **ร่าง ยังไม่ได้ลงมือทำ** · 20 พ.ย. 2026 · ตัวเลขทั้งหมดเป็นจุดเริ่มต้น ต้องจูนด้วย `npm run sim` / `npm run tune`

## 1. จังหวะเกมตอนนี้ (จากโค้ด)

| อะไร | ค่า |
|---|---|
| ความยาวการสู้ | 7–13 วิ (วัน 1–3) · 10–18 วิ (วัน 4–7) · 15–26 วิ (วัน 8+) |
| ช่อง skill | 3 (วัน 1–3) → 4 (4–6) → 5 (7–9) → 6 (10+) ซื้อเพิ่มได้ถึง 8 |
| รอบ | ชนะ 10 หรือ HP หมด ≈ 10–13 วัน |
| สกิล | 15 shared (4 กลุ่ม) + 3 กลาง (ใจเหล็ก ฟันเฟือง เร่งเครื่อง) + 8 unique |
| ความสดใหม่ | โบนัสต่อโซ่ (chain) สุ่มใหม่ทุกครั้งที่ซื้อ → แต่ละรอบเส้นทางไม่เหมือนกัน |

ข้อสรุปเรื่องจังหวะ: **Ultimate ต้องออกได้ 1 ครั้งต่อการสู้** (การสู้สั้นเกินกว่าจะมีหลายรอบ) และ **ควรปลดล็อคกลางรอบ** (วัน 3–5) ครึ่งแรกเรียนรู้สาย ครึ่งหลังได้ของใหญ่ ช่วงท้ายเก็บเป็น Lv2 = "บิวด์ในฝัน"

## 2. Research: เกมอื่นทำ "ท่าไม้ตายประจำตัว" + "สาย" อย่างไร

| เกม | ทำแบบไหน | เอามาใช้ |
|---|---|---|
| **TFT** | Trait มี breakpoint 2/4/6 เห็นตัวนับบนจอ · ultimate ของยูนิตชาร์จด้วยมานา | ตัวนับสาย + breakpoint ("อีก 1 ชิ้น") — ตัวกระตุ้นซื้อที่แรงที่สุดของแนวนี้ |
| **Hearthstone Battlegrounds** | Hero power ต่างกันทุกตัว บางตัวเป็น *quest* (ทำ X ครั้ง → ได้รางวัล) บางตัว passive บางตัวกดใช้ | ultimate แต่ละตัวมีเงื่อนไขคนละ "ชนิด" — ทำให้ฮีโร่แต่ละตัวเล่นต่างกันจริง ไม่ใช่แค่ตัวเลขต่าง |
| **The Bazaar** | ไอเทมประจำฮีโร่ + สายใน (Burn/Poison/Freeze/Haste) ข้ามฮีโร่ได้บางส่วน | สายเป็นของกลาง แต่ฮีโร่ "เจ้าของสาย" ได้ ult — เล่นสายอื่นได้ แต่เสียโบนัสใหญ่ |
| **Backpack Battles** | Subclass item ปลดตอนรอบกลาง เปลี่ยนวิธีเล่นกลางรัน | ปลด ult กลางรันจาก "สร้างบิวด์ตามเงื่อนไข" ไม่ใช่ซื้อด้วยเงินตรงๆ |
| **Slay the Spire** | กลไกเฉพาะตัว (orb, stance) ทำให้ตัวละครจำได้ | ult ต้องสอน "ตัวตน" ของสาย เช่น แม่มดน้ำแข็ง = ร่ายน้ำแข็งครบแล้วระเบิด |
| **Super Auto Pets / Skill Legends Royale** | การสู้ดูอย่างเดียว ไม่มีปุ่มกด | ult ต้องยิงอัตโนมัติ และต้องมี "ช็อตเด็ด" ให้เห็นใน replay (cut-in) |

หลักที่ได้:
1. **เห็นเป้าหมายในร้าน** (ตัวนับ ❄ 2/3) ดีกว่าเป้าหมายซ่อน — สร้างความรู้สึก "อีกนิดเดียว" ตาม vision
2. **ชนิดเงื่อนไขต้องต่างกัน** ไม่ใช่ทุกตัวชาร์จมานาเหมือนกัน — ทำให้ 8 ตัวรู้สึก 8 แบบ
3. **ไม่บังคับ**: เล่นนอกสายได้ ult เป็นรางวัลของการตั้งใจ ไม่ใช่ภาษีของการไม่ตั้งใจ
4. **ช็อตเด็ดใน replay**: ult = ช่วงไคลแมกซ์ที่คนจะแชร์

## 3. 8 สาย (1 ฮีโร่ = เจ้าของ 1 สาย, 2 สาย = 1 กลุ่มเดิม)

กลุ่มเดิม 4 กลุ่ม (tank/burst/scaling/control) ยังอยู่ เพราะโบนัสต่อโซ่ `arch:` ใช้อยู่ แต่ละกลุ่มแตกเป็น 2 สาย

| กลุ่ม | สาย | เจ้าของ | shared ตอนนี้ | ขาด |
|---|---|---|---|---|
| tank | 🛡 **ป้อมโล่** | อัศวิน | ยกโล่ · ผิวหิน · ชำระล้าง | — |
| tank | 🌵 **หนาม** | นักรบหนาม | เกราะหนาม | +2 |
| burst | 🎯 **ปลิดชีพ** | นักฆ่า | ทุบหนัก · รวมพลัง | +1 |
| burst | ⚔ **ตีรัว** | นักดาบคู่ | ฟัน · แทงเร็ว | +1 |
| scaling | 💪 **คลั่ง** | นักรบคลั่ง | ฝึกฝน · กินฟื้นแรง · ขยายพลัง | — |
| scaling | 🔥 **เพลิง** | นักเวทเพลิง | จุดไฟ | +2 |
| control | ❄ **น้ำแข็ง** | แม่มดน้ำแข็ง | ลูกน้ำแข็ง | +2 |
| control | ⏳ **เวลา** | จอมเวทเวลา | ลมหนาว · สลายเวท | +1 |
| กลาง | ⚙ — | ทุกตัว | ใจเหล็ก · ฟันเฟือง · เร่งเครื่อง | ไม่นับสายไหน |

→ ต้องเพิ่ม **shared skill ใหม่ ~9 ตัว** ให้ทุกสายมี 3 shared + 1 unique = 4 ชิ้น (ตัวอย่าง: หนาม "เปลือกเม่น", เพลิง "น้ำมันราด" / "ลมเพลิง", น้ำแข็ง "หมอกเยือก" / "หอกน้ำแข็ง" ฯลฯ — ไอเดียละเอียดค่อยทำหลังตกลงโครง) ไม่ต้องเพิ่มเอฟเฟกต์ใหม่ในเอนจิน ใช้ effect เดิมผสมกันได้หมด

สกิลบางตัวอาจนับ 2 สายได้ (เช่น ขยายพลัง = คลั่ง + เพลิง) เปิดทางบิวด์ลูกผสม

## 4. การปลดล็อค Ultimate (ระดับรอบ)

**แนะนำ: นับชิ้นในสาย (unique นับด้วย)**

| ชิ้นในสายของฮีโร่ใน list | ได้อะไร | คาดว่าเกิด |
|---|---|---|
| 3 | **Ultimate Lv1** | วัน 3–5 (มี 3–4 ช่อง) |
| 5 | **Ultimate Lv2** (แรงขึ้น + เงื่อนไขเต็มเร็วขึ้น 30%) | วัน 7–10 (5–6 ช่อง) — "บิวด์ในฝัน" |

ทำไมแบบนี้เข้า pace เรา:
- ร้านมี 5 ช่อง ต่อวันได้เห็นสกิลในสายบ่อยพอ แต่ไม่ได้ทุกวัน → ต้องตัดสินใจ (ล็อคร้าน, reroll)
- **แรงดึงสองทาง** = ความสดใหม่: โบนัสต่อโซ่สุ่มใหม่ทุกรอบ ดึงไปสายอื่น ส่วน ult ดึงให้อยู่สายตัวเอง แต่ละรอบสมดุลไม่เหมือนกัน
- ไม่ต้องใช้เงิน ไม่มีปุ่มซื้อ ult → ไม่ชนหลัก "ไม่มีพลังที่ซื้อได้"

ทางเลือกอื่นที่พิจารณาแล้ว:
| แบบ | ข้อดี | ข้อเสีย |
|---|---|---|
| unique skill ถึง Lv2 | ง่าย | ไม่ดันให้สร้างสาย ทุกคนแค่อัปตัวเดียว |
| ถึงวันที่ X ได้เลย | ทุกคนได้ | ไม่มีเป้าหมาย ไม่มี "อีก 1 ชิ้น" |
| ซื้อการ์ด ult ในร้าน | ชัด | กลายเป็นเรื่องเงิน/ดวง ไม่ใช่บิวด์ |
| ใช้ช่อง "พลังพิเศษ" (last chance) | ผูกกับระบบเดิม | ได้เฉพาะคนกำลังแพ้ |

## 5. Ultimate 8 ตัว — เงื่อนไขคนละชนิด

ยิงอัตโนมัติ **1 ครั้งต่อการสู้** · มีแถบเติมใต้ฮีโร่ · ตอนยิงมี cut-in + ชื่อท่า

| ฮีโร่ | ชนิดเงื่อนไข | เงื่อนไข (Lv1) | ท่า | ผล (Lv1) |
|---|---|---|---|---|
| อัศวิน | **สะสมทรัพยากร** | ได้โล่รวม ≥ 60% เลือดสูงสุด | ป้อมจันทรา | ตีเท่าโล่ที่มี ×1.5 โดยโล่ไม่หาย |
| นักรบหนาม | **โดนตี** | โดนตี 12 ครั้ง | สวนหนาม | 4 วิ หนามสะท้อน 100% (ไม่มีเพดาน 75%) + ศัตรูฟื้นเลือดไม่ได้ |
| นักฆ่า | **เลือดศัตรู** | ศัตรูเลือด < 40% ครั้งแรก | เงาจันทร์ | ตีทันที ×3 ของการตีแรงสุดที่ทำไป ไม่สนโล่ |
| นักดาบคู่ | **นับการตี** | ตีครบ 15 ครั้ง | ร่ายรำดาบ | 3 วิ คูลดาวน์ทุก skill ลด 50% |
| นักรบคลั่ง | **ใกล้ตาย** | โดนตีจนตาย | ไม่ยอมตาย | รอดที่ 1 HP ฟื้น 20% + พลัง +2 |
| นักเวทเพลิง | **ดีบัฟบนศัตรู** | ไฟบนศัตรู ≥ 4 กอง | สุริยะดับ | ระเบิดไฟที่เหลือทั้งหมดทันที ×1.3 แล้วจุดใหม่ 1 กอง |
| แม่มดน้ำแข็ง | **ร่ายสกิลในสาย** | ร่ายสกิลสาย ❄ ครบ 3 ครั้ง | ยุคน้ำแข็ง | แช่แข็ง 2 วิ (ไม่โดนผลลดจากโดนถี่ แต่ยังอยู่ใต้เพดานต่อการสู้) + ทุบน้ำแข็งครั้งถัดไป ×2 |
| จอมเวทเวลา | **ควบคุมศัตรู** | ใส่ช้า/ถ่วงเวลารวม 4 ครั้ง | ย้อนเวลา | skill ทุกตัวของตัวเองพร้อมใช้ทันที |

Lv2 = เงื่อนไขเร็วขึ้น 30% + ผลแรงขึ้น ~40% (ไม่เพิ่มจำนวนครั้ง)

เช็คกับหลัก vision:
- **ฮีโร่เดียวกัน = แรงเท่ากัน** ✔ (ไม่มีของซื้อ)
- **การคุมไม่ล็อคตาย** ✔ (ยุคน้ำแข็งยังอยู่ใต้เพดาน, ย้อนเวลาเป็นบัฟตัวเอง ไม่ใช่คุมเพิ่ม)
- **มีทางสู้กลับ**: สลายเวทลบบัฟ ult ที่ค้างได้ (สวนหนาม, ร่ายรำดาบ) · ชำระล้างลบแช่แข็งของยุคน้ำแข็ง · โล่กัน เงาจันทร์ ไม่ได้ แต่ฟื้นเลือดหนีเกณฑ์ 40% ได้

## 6. เป้าหมายตอนจูน (ใส่ใน `npm run sim`)

| ค่า | เป้า |
|---|---|
| ult ยิงในการสู้ที่ปลดแล้ว | ≥ 75% (นักฆ่า/นักรบคลั่งเป็นเงื่อนไข ≥ 50%) |
| เวลาที่ยิง | กลางการสู้ 40–70% ของความยาว (ไม่ใช่วิแรก ไม่ใช่หลังจบ) |
| win rate บิวด์ที่ปลด ult vs ไม่ปลด (ฮีโร่เดียวกัน) | +3 ถึง +7 จุด (ดึงแต่ไม่บังคับ) |
| win rate ฮีโร่ | 45–55% ทุกตัว ทุกวันที่วัด |
| ความยาวการสู้ / 0-skill / locked | อยู่ในเป้าเดิม |

## 7. UI

- **ร้าน**: ชิป `❄ 2/3` ข้างฮีโร่ · สกิลในร้านที่นับสายมีขอบสีสาย + ป้าย "อีก 1 ชิ้น → ปลด ult" · ตอนปลดมีเอฟเฟกต์ + เสียง
- **การสู้**: แถบ ult ใต้ HP เติมตามเงื่อนไข (แสดงตัวเลข เช่น 2/3 ❄) · ยิงแล้วมี cut-in ชื่อท่า 0.6 วิ (ไม่หยุดเกม)
- **หน้าอธิบาย/จบรอบ**: บรรทัด "ult ยิงวินาทีที่ 9.4 ทำดาเมจ 38" · บิวด์ไม่ได้ปลด → บอก "ขาดอีก 1 ชิ้น"
- **tutorial**: บทที่ 3 ชี้ตัวนับสาย ("chain เปลี่ยนทุกรอบ แต่สายของฮีโร่ไม่เปลี่ยน")

## 8. เชื่อมกับ loop GameFi

- **Seal / Build Card / Legend build**: การ์ดแสดงสาย + ระดับ ult → คนเช่าบิวด์เลือกตามสายได้ทันที
- **Rule-set bot**: bot รู้จักสายของตัวเองอยู่แล้ว (`botWant`) เพิ่ม "ซื้อเพื่อนับสาย"
- **กฎประจำวัน** (ขั้นถัดไป): ใช้ตัวนับสายเดียวกัน เช่น "วันนี้ ult ปลดที่ 2 ชิ้น" / "วันนี้สายเพลิงนับสองเท่า"
- **ฮีโร่หมุนเวียนฟรี**: ฮีโร่แต่ละตัวมี ult ต่างกัน → การหมุนเวียนรู้สึกเป็นของใหม่จริง

## 9. แผนลงมือ (หลังตกลง)

1. **ป้ายสาย**: เพิ่ม `line` ใน SkillDef + ชิปในร้าน/ตัวนับ — ยังไม่เปลี่ยนบาลานซ์
2. **สกิลใหม่ ~9 ตัว** ให้ทุกสายครบ 4 ชิ้น · จูนด้วย sim
3. **เอนจิน ult**: hook ใหม่ (`onCast`, ตัวนับ), event `ult` ใน replay, bump `SIM_VERSION`
4. **จูน** `npm run tune` จนผ่านเป้าในข้อ 6
5. **bot + UI + tutorial + e2e** แล้ว deploy list (grid ตามทีหลัง)
