# Mochi Moon: facts for pitches, updates and submissions

The one place to take numbers and claims from when writing a deck, a weekly update, a Colosseum answer or a post.
Keep it current: every change to the game, the team, the money model or the status updates this file in the same
commit or the same session.

## Rules

1. **Newest wins.** When two sources disagree, the newer one is right. Dates are in the source table below.
   An owner ruling in chat beats every document; this file records those rulings with their date.
2. **Code beats documents for game numbers.** Heroes, skills, relics, HP and wins come from the code. Run
   `npm run facts` to refresh the block below. The PDFs in `docs/archive/hackathon/` have old numbers, such as 8 heroes,
   168 skill variants, 8 wins and 20 HP.
3. **Money model: always the newest decision** (section below). Do not mix models from older documents.
4. **Built vs planned.** Every claim says whether it exists today or is planned. Never write a planned feature as
   if it ships today.
5. **Real vs simulated.** Bot and AI playtests (sim runs, agent playtests, MiroFish) are labelled as such. Never
   present them as real users.

## Money model (newest decision)

**Ruling 2026-11-28 (owner, decision D2 in the "v5 Monetization" doc tab):** players sell all power to each other;
the house sells status, volume and looks, never power. No game token. At launch Moon Dust (shown in the game as
**Moonstone**) is an item players trade with each other on the Moon Market (listings and escrowed buy orders); the
house never sells it, never promises a price and runs no USDT ↔ Dust exchange; it takes a 10% fee on trades. The
Moon Fund goes 100% to the Ranked prizes (USDC). After a $1,500 Moon Fund season, 30% of the fund places weekly buy
orders for Dust at no more than the 7-day median and burns what it buys. Fallback: if demand stays below 0.06 Wants
per player-week for a season, the house sells bound T3 Kit at 2× the market median. **All planned; nothing of it is
live.** Other v5 numbers (pass ฿229, Patron ฿690, fee splits, bands ×1.18 / ×1.30) are team proposals the owner has
not confirmed yet: do not quote them as decided.

What this replaces: the Build Card / Build Library streams in the table below (18–19 Nov) are no longer the plan.
The table is kept for history.

**Ruling 2026-11-20 (owner): GameFi on blockchain first; legal review is not a design constraint.** This lifts the
"wait for a lawyer" holds in the 19 Nov overview. Structure comes from the 19 Nov overview, prices from the
18 Nov pitch (no newer document sets prices).

## Onchain (built)

Code in `onchain/` of the game repo (merged from `ten852456/mochi-onchain` on 2026-11-27; `onchain/README.md`,
`onchain/docs/RANDOMNESS.md`):
- **Program:** `mochi-game`, Anchor 1.0.2, on Solana **devnet** (`7yVgjzySuXwBeRJ18ZhunetqBz8ZTBNGiQVkw1or7w2r`,
  deployed 2026-11-26; 774 KB). The earlier devnet program `Fu3JUGUS…` (sim v13) was closed on 2026-11-26.
- **Runs in a MagicBlock private ephemeral rollup (TEE)**, ephemeral-rollups-sdk 0.16.2. Player, run secret, season
  secret, pool and ranking accounts are delegated and private (the secrets and the pool / ranking: readable by
  nobody, not even the admin), so opponents' builds stay hidden until the season ends. Only the season's final
  results come back to Solana, scrubbed of secrets.
- **Engine:** a bit-exact Rust port of the TS sim v22 (integer-only, runs on SBF): 20,000 fights and 20,000 runs
  match the TS game exactly.
- **Whole run on chain:** hero pick, shop actions (`act`, `act_batch` up to 32), fights against stored player ghosts
  (compressed builds) or bots, relics, last chance, marks, `finish_run`.
- **Randomness:** one MagicBlock VRF request per run, mixed with a committed season secret into a run secret that
  nobody can read; every random action (shop rolls, rerolls, relics, marks, fight seed, opponent) is requested
  first and rolled by a later VRF callback, so it cannot be previewed or retried. The run secret is revealed when
  the run ends, so anyone can re-check every roll.
- **Wallet:** Phantom owner approves twice on first use; then a browser session key (at most 7 days, revocable)
  plays with no pop-ups. It can only call play instructions and never moves SOL.
- **Season end:** top-16 ranking and a Merkle root of rewards published on Solana; players claim with a proof
  (in-game currency).
- **Tested on devnet 2026-11-26 (19/19):** setup and privacy of every account, a full run with the real VRF oracle
  (every fight replays to the same result in the TS game), season end back to Solana, claim (forged and double
  claims rejected).
- **Not yet:** audit, mainnet, the public server build (Railway service).

Plans still open (19 Nov overview): Legend builds (soulbound trophies), Challenge Blinks, a server + Merkle-root
fallback if TEE costs do not fit.
